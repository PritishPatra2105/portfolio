Business Problem

Content strategy and programming teams require clear, continuous visibility into how a vast entertainment catalog breaks down across genres, release eras, geographic origins, and audience ratings. Without an aggregated, interactive analytical model, identifying underserved genre segments or shifts in catalog renewal patterns is cumbersome and error-prone.

Analytical Approach

Used SQL to query, clean, and structure the catalog dataset, resolving multi-value delimitations and standardizing dates. Built an interactive Power BI report with DAX measures and coordinated visual filters:

  • Data Normalization via SQL: Unnested multi-value genre strings and comma-separated cast/country attributes into clean relational structures using cross-joins and string tokenization functions.
  • Temporal Modeling: Standardized dates added to the platform versus original theatrical/broadcast release years to evaluate catalog vintage versus acquisition speed.
  • DAX Measures: Implemented calculated measures for Movies vs TV Show ratios, decade-over-decade title additions, and rating tier concentrations.
  • Visual Hierarchy: Engineered linked slicers (Year, Content Type, Genre, Country) with cross-highlighting across bar charts, trend lines, and donut distributions.
SQL • Genre Breakdown & Decade Growth Aggregation 
WITH CleanCatalog AS (
    SELECT 
        show_id,
        type,
        title,
        release_year,
        rating,
        -- Group into decade buckets for trend analysis
        CONCAT(FLOOR(release_year / 10) * 10, 's') AS release_decade,
        TRIM(value) AS primary_genre
    FROM netflix_titles
    CROSS APPLY STRING_SPLIT(listed_in, ',')
    WHERE release_year IS NOT NULL
      AND rating IS NOT NULL
)
SELECT 
    primary_genre,
    type,
    release_decade,
    COUNT(DISTINCT show_id) AS title_count,
    ROUND(
        COUNT(DISTINCT show_id) * 100.0 / 
        SUM(COUNT(DISTINCT show_id)) OVER(PARTITION BY release_decade), 
        2
    ) AS pct_of_decade_total
FROM CleanCatalog
GROUP BY primary_genre, type, release_decade
HAVING COUNT(DISTINCT show_id) >= 50
ORDER BY release_decade DESC, title_count DESC;

VAR TotalCatalog = COUNTROWS('Netflix_Titles')

Key Insights Surfaced

The structured catalog analysis revealed clear structural characteristics of the catalog:

  • Format Distribution: Feature movies represented approximately two-thirds (67%) of total titles, while episodic TV series comprised the remaining 33%.
  • Dominant Content Genres: Dramas, International Films/Series, and Comedies formed the core majority of offerings across both movie and television categories.
  • Acquisition Era Trajectory: Over 80% of catalog titles were originally released after 2010, reflecting a heavy strategic focus on modern, high-definition catalog assets.
  • Maturity Rating Profile: TV-MA and TV-14 classifications dominated the television offerings, underscoring targeting towards young-adult and mature demographic segments.
