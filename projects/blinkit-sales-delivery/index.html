Business Problem

Operations and category teams needed a consolidated view of order volumes, revenue, and delivery performance to spot trends across regions and product categories. Without unified reporting, operational managers had to stitch together fragmented transactional extracts, leading to delayed fulfillment bottleneck identification and missed inventory rebalancing opportunities.

Analytical Approach

To solve this challenge, I designed an end-to-end analytical pipeline structured across three core phases:

  • SQL Extraction & Cleansing: Wrote multi-stage SQL queries with Common Table Expressions (CTEs) to handle null values, remove duplicate order logs, parse delivery timestamps, and calculate dispatch latency.
  • Data Modeling: Built a star-schema model in Power BI linking Fact Orders with Dimension Tables (Dim_Stores, Dim_Products, Dim_Calendar, Dim_Geography).
  • DAX Measure Engineering: Formulated custom DAX measures for dynamic SLA calculation, Year-over-Year revenue growth, and weighted fulfillment time.
  • Executive Visual Architecture: Designed a responsive, high-contrast user interface with drill-through capability from high-level regional views down to store-level performance.
SQL • Regional Fulfillment & SLA Performance Query 
WITH DeliveryMetrics AS (
    SELECT 
        o.order_id,
        o.store_id,
        s.region_name,
        p.category_name,
        o.order_value,
        DATEDIFF(MINUTE, o.order_placed_at, o.delivered_at) AS delivery_duration_min,
        CASE 
            WHEN DATEDIFF(MINUTE, o.order_placed_at, o.delivered_at) <= 15 THEN 1 
            ELSE 0 
        END AS is_within_sla
    FROM fact_orders o
    JOIN dim_stores s ON o.store_id = s.store_id
    JOIN dim_products p ON o.product_id = p.product_id
    WHERE o.order_status = 'Delivered'
      AND o.order_date >= DATEADD(MONTH, -1, GETDATE())
)
SELECT 
    region_name,
    category_name,
    COUNT(order_id) AS total_orders,
    SUM(order_value) AS total_revenue,
    ROUND(AVG(delivery_duration_min * 1.0), 2) AS avg_delivery_time,
    ROUND((SUM(is_within_sla) * 100.0) / COUNT(order_id), 2) AS sla_adherence_pct
FROM DeliveryMetrics
GROUP BY region_name, category_name
ORDER BY total_revenue DESC;
DAX • Dynamic SLA Adherence Measure 
SLA Adherence % = 
VAR TotalDelivered = 
    CALCULATE(
        COUNTROWS(fact_orders),
        fact_orders[order_status] = "Delivered"
    )
VAR DeliveredWithinSLA = 
    CALCULATE(
        COUNTROWS(fact_orders),
        fact_orders[delivery_duration_min] <= 15,
        fact_orders[order_status] = "Delivered"
    )
RETURN
    DIVIDE(DeliveredWithinSLA, TotalDelivered, 0)

Key Insights Surfaced

Through multidimensional slicing in Power BI, the analysis revealed actionable operational dynamics:

  • Category Revenue Dominance: Fresh Fruits & Vegetables and Daily Staples accounted for the highest order frequencies and revenue volume across urban clusters.
  • Regional Bottlenecks: Certain high-density micro-markets experienced delivery latency peaks between 6:00 PM – 9:00 PM, identifying the exact dark stores requiring additional delivery fleet capacity.
  • Basket Size Correlation: Orders bundling personal care items alongside grocery staples yielded a significantly higher Average Order Value (AOV), highlighting cross-merchandising potential.
